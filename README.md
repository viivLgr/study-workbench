# 每日学习笔记

一个用于归档学习文档并生成快速可阅读总结的个人知识库。

## 📱 工作台（主要入口）

**打开 `工作台.html` 即可使用**（用浏览器打开，推荐 Chrome / Safari）。

工作台功能：
- **今日总结置顶**：当天最新文档的总结醒目展示在首页
- **历史文档浏览**：按日期倒序排列，支持搜索和语言筛选
- **折叠展开**：核心要点 / 关键概念 / 实践要点 / 点评 可逐项展开
- **查看原文**：点击"查看原文"按钮弹窗显示原始文档
- **统计面板**：已学习文档数、连续学习天数、本周完成数
- **暗色/亮色主题**：右上角按钮切换
- **移动端适配**：手机浏览器也能流畅阅读

## 📂 目录结构

```
每日学习笔记/
├── 工作台.html            ← 【主要入口】可视化工作台，浏览器打开即用
├── README.md              ← 本说明文件
├── 索引.md                ← 文本备份索引（日期 / 标题 / 状态）
├── 归档/                  ← 原始文档 Markdown 备份
│   └── YYYY-MM-DD_文档标题/
│       └── 原文.md
└── 总结/                  ← 每日总结 Markdown 备份
    └── YYYY-MM-DD_文档标题_总结.md
```

> 工作台 HTML 是主要查看入口；Markdown 文件作为底层数据备份保留，方便版本管理和导出。

## 🔄 使用方式

1. **你发文档**：随时把当天要学习文档的内容发给我（直接粘贴文本、发文件都可以，中英文均可）
2. **我处理**：我会完成以下工作
   - 分析整理后生成一份**标准学习版总结**
   - 将数据写入 `工作台.html`（刷新即可看到今日内容置顶）
   - 将原始文档归档到 `归档/` 目录
   - 将总结保存到 `总结/` 目录
   - 更新 `索引.md` 汇总表
3. **你阅读**：打开工作台 HTML，今天的总结在首页，历史文档在下方

## 📋 总结结构（标准学习版）

每份总结包含以下模块：

| 模块 | 内容 |
|------|------|
| 📌 一句话概览 | 用一句话概括全文核心，让你 10 秒抓住重点 |
| 🔑 核心要点 | 3-7 条关键信息，每条一句话讲清楚 |
| 📖 关键概念解释 | 文档中的重要概念/术语，用通俗语言解释 |
| 🛠 实践要点 | 可以直接落地应用的建议或行动项 |
| 💡 我的点评 | 对文档价值、适用场景、局限性的简要评价 |
